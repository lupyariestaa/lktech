# Folder logo teknologi

Simpan logo teknologi di sini sebagai file SVG (disarankan) atau PNG.

Contoh: `react.svg`, `laravel.svg`, `python.png`.

Untuk data default, isi field `logo` pada `TECH_STACK` di `src/lib/content.ts`,
mis. `{ name: "React", logo: "/tech/react.svg", color: "#61DAFB" }`.
Untuk daftar yang sedang tampil di situs, gunakan **Admin → Konten → Teknologi**.

Panduan lengkap: lihat `docs/SETUP-LOGO-TEKNOLOGI.md`.

Selama `logo` masih kosong, kartu akan menampilkan placeholder (inisial + warna brand).
