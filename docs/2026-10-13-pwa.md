# PWA — Installable, Cache Ringan, Offline Fallback (Tema 3.5, B2)

> **Status:** ✅ Selesai (kode).
> **Disusun:** 2026-10-13. **Basis:** `docs/2026-10-06-roadmap-pengembangan.md` §3.5 & §6.
> **Cakupan:** PWA dasar (manifest + service worker + offline fallback).
> **DI LUAR CAKUPAN:** **Web Push** (butuh service worker + kunci VAPID + backend

---

## 1. Ringkasan & Tujuan

Membuat LKTech **installable** (Add to Home Screen) di ponsel/desktop, dengan
**cache aset ringan** agar muat ulang lebih cepat, dan **halaman offline** yang
jujur saat jaringan putus. Ini prasyarat teknis untuk Web Push nanti.

**Prinsip (mengikuti pola proyek):**
- **Aman & fail-safe:** PWA tidak boleh mengganggu alur transaksi. Service worker
  **tidak pernah** meng-cache `/api/*`, `/admin/*`, atau permintaan non-GET.
- **Etis:** folder offline = data nyata minim; tidak ada klaim palsu.
- **Backward-compatible:** tanpa dukungan SW (browser lama) situs tetap jalan normal.
- **Tanpa dependensi baru:** memakai `app/manifest.ts` (MetadataRoute Next) + `sw.js`
  vanilla. Tidak menambah paket (mis. `next-pwa`).

## 2. Keputusan Desain

| # | Keputusan | Alasan | Alternatif ditolak |
| - | --- | --- | --- |
| K1 | **Service worker vanilla** `public/sw.js` | Tanpa dependensi; transparan; sesuai prinsip "stdlib/native dulu" | `next-pwa`/Workbox (paket baru + build step) |
| K2 | **Manifest via `app/manifest.ts`** | Konvensi Next; tipe aman; auto `<link rel="manifest">` | File statis `manifest.json` (tak ikut tipe/konstanta) |
| K3 | **Navigation: network-first** → cache → `/offline` | Konten dinamis (produk/order) harus segar; offline hanya fallback | cache-first (menyajikan data basi) |
| K4 | **Aset statik: stale-while-revalidate** | Cepat + tetap ter-update diam-diam | cache-first murni (basу) |
| K5 | **Jangan cache `/api`, `/admin`, non-GET** | Keamanan & kesegaran (order, auth, pembayaran) | cache-by-default |
| K6 | **Versi cache tunggal** `lktech-pwa-v1` di `src/lib/pwa.ts` **dan** `public/sw.js` | Naikkan versi = purge cache lama; diuji agar **tak drift** | satu sumber (tak bisa: SW vanilla tak impor TS) |
| K7 | **Ikon eksplisit** di `public/icons/*` | URL stabil untuk manifest (icon Next ber-hash) | rujuk `app/icon.png` (URL tak stabil) |

## 3. Alur / Arsitektur

```
app/manifest.ts ──(konstanta bersama)── src/lib/pwa.ts
        │                                     ▲
        │  icons: /icons/icon-{192,512}.png   │ PWA_CACHE (versi)
        ▼                                     │
   <link rel="manifest">                  scripts/pwa.test.ts
                                              ▲  (assert versi sama)
public/sw.js ── cache "lktech-pwa-v1" ────────┘
   • install : precache shell terbatas (/offline, manifest, ikon)
   • fetch   : navigation → network-first → cache → /offline
              statik (_next/static, gambar, font) → stale-while-revalidate
              /api, /admin, non-GET → lewati (jaringan langsung)
   • activate: hapus cache versi lama

src/components/pwa-register.tsx ── navigator.serviceWorker.register("/sw.js")
   (di-mount di root layout; aman SSR; no-op bila SW tak didukung)
```

## 6. Web Push — DITUNDA

Web Push butuh: kunci **VAPID**, penyimpanan langganan (`push_subscriptions`),
endpoint kirim, dan izin pengguna. Menyentuh privasi & kredensial → **fase
tersendiri**. Titik masuknya sudah disiapkan (SW terpasang) sehingga penambahan
`push`/`pushsubscriptionchange` listener tinggal ditambahkan.

## 7. Catatan Operasional

- **Update rilis:** saat mengubah `sw.js`, **naikkan** `lktech-pwa-v1` → `v2` di
  `src/lib/pwa.ts` **dan** `public/sw.js` (uji `test:pwa` menolak jika beda).
- **Verifikasi manual (pemilik):** buka DevTools → Application → Service Workers
  (SW aktif); Manifest (installable, ikon tampil); matikan jaringan → muat `/`
  → halaman `/offline` muncul.
